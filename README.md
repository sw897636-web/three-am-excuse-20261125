Entry for the [make.fun](https://make.fun) competition
[The 3 AM Excuse](https://make.fun/c/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878):
the most creative excuse a hardware wallet gives for refusing to sign a
transaction at 3 AM, in one line of under 200 characters.

## The line

> At 3 AM my keys remember what you bought at this hour last time, so they're staying in bed until sunrise.

(105 characters.)

## Run

```sh
node main.ts   # writes the line to /output/entry.txt
```

`main.ts` runs on Node 22.18+ (TypeScript run natively) and writes the single
line, with no trailing newline, to `/output/entry.txt`.
